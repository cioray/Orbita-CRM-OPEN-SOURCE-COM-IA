# Convivência na comunidade

Queremos um ambiente acolhedor para pessoas com diferentes experiências, idiomas e níveis técnicos. Seja respeitoso, foque nas ideias e aceite críticas construtivas.

Não são aceitos assédio, discriminação, ameaças, divulgação de dados privados ou ataques pessoais. Não exponha conversas ou informações de clientes para demonstrar um problema.

Mantenedores podem moderar conteúdo, encerrar discussões e restringir participação quando necessário, considerando contexto e gravidade. Relate incidentes pelo contato privado disponibilizado no perfil do mantenedor, sem publicar dados pessoais em issues. Este projeto ainda não possui uma equipe dedicada de moderação.
